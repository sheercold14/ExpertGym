## 重点观察

| 指标 | 判断 |
|---|---|
| `gate_delta_max` | old B 首轮约 `0.0137`；b1 预计约 `0.029`，若超过 `0.04` 需警惕过冲 |
| `grad_norm_max` | 若与 old B 相近，差异主要来自 lr |
| task gate | memory/code 是否更快上升，tool 是否被快速压低 |
| selected OPD rows | 若后期 OPD rows 迅速耗尽，继续高 lr 可能只剩 retention 阻尼 |
| rollout reward | proxy reward 若明显下降，停止并评估前一轮 checkpoint |
