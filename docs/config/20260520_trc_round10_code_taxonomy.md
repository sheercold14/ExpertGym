## Decision

Use Tool/Memory quick gate first. Only run CURE Code if:

- Tool mean `>=0.79`
- Memory mean F1 `>=0.76`

If R10A/R10B pass Tool/Memory but still fail Code, the result supports the claim that current CodeP0 train rows are still not a sufficient proxy for CURE/LiveCodeBench, even with better taxonomy coverage.
