# 2026-05-21 RCRF v1

## 目标

这版只验证一个极简机制假设：

> task vector merge 的有效单元不是 expert-level coefficient，而是 response-conditioned module residual：`Delta W_m h_m`。

因此不训练 gate，不用 reward 优化，不追某个 expert 系数。只根据 signed utility probe 在每个 `layer × module × expert` 上判断 residual 是能力、协同、冲突还是噪声，然后生成 gate。

## 方法

RCRF = Response-Conditioned Residual Filtering。

输入：

- mode manifest: `/tmp/shared-storage/OnPolicy/modes/opvec4/mode_manifest.json`
- signed utility summary: `/tmp/shared-storage/ExpertGym/attention_matrix/signed_utility_signature_s4_layers8_alllinear_20260521/signed_utility_summary.json`

每个参数位置计算：

- `owner_effect`: 该 expert residual 对 owner task 响应 span 的一阶 utility。
- `cross_positive`: 对其他 task 的正向 utility，视作潜在协同。
- `cross_harm`: 对其他 task 的负向影响。
- `conflict_score`: 同层 expert residual cosine 的负向冲突。
- `expression_ratio`: `Delta W h` 能量相对该 expert 的中位数。
- `noise_score`: 低能或符号不稳定。

规则：

| residual 类型 | 操作 |
| --- | --- |
| owner utility 高、稳定 | 保留或轻放大 |
| cross-task agreement 高 | 轻放大 |
| conflict / harm 高 | 压低 |
| low energy / unstable | 压低 |
| `q/k` routing 残差 | 更保守 |
| MLP 残差 | 作为能力主通道，允许更充分表达 |

## 候选

只保留两个：

| candidate | 作用 |
| --- | --- |
| `rcrf` | 主方法：utility + agreement + conflict + noise |
| `energy_only` | 最小消融：只看 `Delta W h` expression energy，不看 signed utility / conflict |
| `no_conflict` | 验证 conflict/harm 项是否必要：保留 owner utility + agreement，但关闭 conflict |
| `owner_only` | 验证 cross-task agreement 是否必要：只保留 owner utility + noise filtering |

Memory 使用 HotpotQA `eval_50 / eval_100` 的 `avg_f1`。

| candidate | Tool quick mean | parallel | parallel_multiple | live_parallel | live_parallel_multiple | Memory eval_50 F1 | Memory eval_100 F1 | 判断 |

对比 SCG-v1 `code_safe`：

| method | Tool quick mean | Memory eval_50 F1 | Memory eval_100 F1 |
| --- | ---: | ---: | ---: |
| SCG-v1 `code_safe` | 0.7813 | 0.7714 | 0.7427 |
| RCRF `rcrf` | 0.7956 | 0.7708 | 0.7567 |

初步结论：

- `rcrf` 相比 `energy_only` 的 Tool live_parallel 从 `0.7500` 提升到 `0.8125`，说明 signed utility / conflict 不是装饰项，而是 Tool 行为稳定性的关键。
- `rcrf` 没有牺牲 Memory；`eval_100` 高于 `energy_only` 和 SCG-v1 `code_safe`。
- 这支持当前最小 insight：有效合并单元是 `Delta W h` 的 response-conditioned residual，而不是 expert-level coefficient。
