# 2026-05-18 Code P0 v3 Calibration Bank

## 目标

构造一个只服务 Code 主线的可审查 calibration bank，用来检验：

```text
train code reward 上升
  -> monitor/guard code reward 上升
  -> formal CURE / LiveBench / LiveCodeBench Code 指标上升
```

这版不改旧的 paper96、sota_calib_v2 或 recoverable101 数据。

## 数据结构

来源只使用 CodeContests train：

```text
/mnt/cache/wuruixiao/users/lsc/ExpertMerging/dataset/CodeContests_train/train/CodeContests_train.json
```

每条 row 的 `reference.metadata` 显式记录：

```text
test_input/test_output          # 当前 CodeRewardAdapter 实际读取的 reward slice
reward_test_input/output        # 同上，显式命名，便于审计
guard_test_input/output         # 同题 held-out test slice，暂不参与训练 reward
reward_test_indices
guard_test_indices
code_bank_role                  # generation/frontier/partial_edge/stable
code_tags
```

默认每题：

```text
reward tests = 6
guard tests = 4
min source tests = 10
```

## 泄漏控制

- 不读取 LiveBench / LiveCodeBench / CURE official prompt、hidden tests、生成结果或答案。
- formal eval case study 只作为方法设计动机，不作为本脚本输入。
- train / monitor / guard 按 CodeContests `task_id` 完全 disjoint。

## 下一步

1. 对 `train_code64` 用 ReasonFlux-Coder、DeepSeek-R1-Distill-Qwen-7B 生成 expert rollouts。
2. 对当前 TA/init1/R1 candidate 在 `train_code64 + monitor_code32 + guard_code32` 上做 state distribution。
3. 只在 Code train reward 和 monitor reward 同步上涨时，进入 R1 scaled layer28 或 joint Tool/Memory/Code 训练。

Expert rollout 入口：

```bash

# DeepSeek-R1-Distill-Qwen-7B

  bash skill/command/run_20260518_code_p0_v3_expert_rollouts.sh
```

如果后续需要把 64 prompts 切到多卡并行，可以设置：

```bash
PROMPT_OFFSET=0 NUM_PROMPTS=16 GPU_LIST=0 POLICY=reasonflux bash skill/command/run_20260518_code_p0_v3_expert_rollouts.sh
PROMPT_OFFSET=16 NUM_PROMPTS=16 GPU_LIST=1 POLICY=reasonflux bash skill/command/run_20260518_code_p0_v3_expert_rollouts.sh
```

这会自动在输出文件名中加入 `offset*_n*`，避免覆盖全量 rollout。

